# Buddy - Virtuaalse Lemmikuga Toimetuste Rakendus

![Buddy Logo](/media/BuddyLogo.svg)

## Ülevaade

Buddy on veebirakendus, mis ühendab igapäevaste ülesannete täitmise virtuaalse lemmikloomaga. Kasutajad saavad valida kassi või koera, täita ülesandeid teenida preemiaid ja hoolitseda oma virtuaalse kaaslase eest. Rakendus on loodud motiveerimaks kasutajaid kohese tasu süsteemi kaudu.

## Peamised funktsioonid

- **Lemmiklooma valik** - Vali endale kaaslaseks kas kass või koer
- **Ülesannete haldus** - Täida igapäevaseid ülesandeid teenimaks oma lemmikule preemiaid
- **Preemiate süsteem** - Täidetud ülesannete eest saad toitu ja mänguasju oma lemmikule
- **Mobiilne disain** - Rakendus töötab nii arvutis kui ka mobiilseadmetes
- **Kontaktvorm** - Lihtne viis ühendust võtta arendajatega
- **Uudiskiri** - Jää kursi kasulike nippide ja väljakutsetega

## Paigaldusjuhised

1. Klooni repositoorium:
``bash
git clone https://github.com/Elikala/Buddy.git


2. Liigu projekti kausta:
cd Buddy

3. Paigalda SASS (kui pole juba olemas):
npm install -g sass

4. Kompileeri SASS failid:
sass scss/style.scss css/style.css


5.Käivita rakendus:
Ava index.html fail oma veebibrauseris
Või kasuta lokaalset serverit (nt Live Server laiendus VS Code'is)


## Kuidas mäng käib:

Vali lemmikloom (kass või koer) mängu lehel
Lisa enda igapäevased ülesanded
Täites ülesandeid teeni preemiaid oma lemmikule
Kasuta preemiaid, et toita ja mängida oma virtuaalse kaaslasega
Jälgi oma edenemist ja näe, kuidas su lemmik kasvab
